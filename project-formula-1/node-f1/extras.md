# 🆕 What's New in This Version

- Added new Drivers to the API.
- Simple and minimal FrontEnd in HTML, CSS, and JavaScript:
  - JavaScript fetches data from the API to dynamically populate the Teams and Drivers cards.
  - Lightweight styling and interactivity, following the minimalistic API approach.

# 🛠 How to Use

1. Make sure the API is running locally on port 3333.
2. Open your browser.
3. Access the FrontEnd via the link: [http://localhost:3333](http://localhost:3333)
4. Explore the Teams and Drivers cards, which are dynamically updated by the API.

> Note: Since this is a minimal API, the FrontEnd is also minimalistic, simply displaying the data in cards.
